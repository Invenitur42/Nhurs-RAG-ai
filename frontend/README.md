# Frontend – RAG Knowledge Base

Next.js 15 (App Router) + TypeScript + Tailwind frontend for the RAG Knowledge Base.

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Make sure the backend is running on `http://localhost:8000`.
